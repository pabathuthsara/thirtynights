# Thirty Nights landing page

A standalone marketing site for the Thirty Nights app. It reuses the app's
Soft Keepsake artwork and includes production routes for the privacy policy,
terms and conditions, support, and account deletion.

## Local development

```bash
npm install
npm run dev
```

The Google Play button targets the production Android package URL:
`com.thirtynights.app`.

No database or Supabase project is required for the website.
