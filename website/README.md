# Thirty Nights landing page

A standalone local marketing site for the Thirty Nights app. It reuses the
app's Soft Keepsake artwork and includes local placeholder routes for the
privacy policy, terms and conditions, and account deletion.

## Local development

```bash
npm install
npm run dev
```

The Google Play button targets the production Android package URL:
`com.thirtynights.app`.

The legal pages and contact address are clearly marked as placeholders and
must be reviewed before launch. No database or Supabase project is required
for this static version.
